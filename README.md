<summary><b>⚡ Binary Search Philosophy</b></summary>

<br>

```java
while (low <= high) {

    int mid = low + (high - low) / 2;

    if (condition(mid))
        high = mid - 1;
    else
        low = mid + 1;
}
```

**Lower Bound**

```text
First index where arr[i] >= target
```

**Upper Bound**

```text
First index where arr[i] > target
```

> Don't memorize binary search.
> **Understand what you're searching for.**
